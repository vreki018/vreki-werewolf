## ต้องมีอะไรบ้าง

- **Windows 10 / 11**
- **AI อย่างน้อย 1 ค่าย**
  - Claude → แพ็ก Claude Pro ขึ้นไป + โปรแกรม **Claude Code** ที่ล็อกอินแล้ว
  - ChatGPT → แพ็ก ChatGPT Plus ขึ้นไป + โปรแกรม **Codex** ที่ล็อกอินแล้ว
  - Gemini → **คีย์ API** จาก [Google AI Studio](https://aistudio.google.com/) (ไม่บังคับ)
- **Node.js 18 ขึ้นไป** (ตัวเกม)
- **Python 3.10 ขึ้นไป** (เฉพาะเสียงพากย์และไมค์) · **ffmpeg** (เฉพาะเสียง Gemini) · **การ์ดจอ NVIDIA** (เฉพาะไมค์)

ไม่ต้องลงเองทีละตัว — ให้ AI ของเราติดตั้งให้ (ดูหัวข้อถัดไป)

### เรื่องโควต้า อ่านก่อนเล่น

1 เกมเรียก AI ราว **30–45 ครั้ง** (ค่าประมาณจากเกมจริงตอนทำคลิป) ทุกครั้งใช้โควต้าแพ็กของเรา
แพ็ก 20 ดอลลาร์อาจเล่นได้แค่ **ไม่กี่เกมต่อ 5 ชั่วโมง** โดยเฉพาะถ้าให้ค่ายเดียวเล่นครบ 6 ที่ · รุ่นใหญ่อย่าง Opus กินโควต้าเร็ว
อยากประหยัด: เลือกหลายค่ายให้แบ่งกัน หรือเปลี่ยนเป็นรุ่นเล็กลงในหน้าตั้งค่า

## ติดตั้ง

1. กดปุ่ม **Code → Download ZIP** ด้านบนหน้านี้ (หรือโหลดจากหน้า Releases) แล้วแตกไฟล์ไว้สักที่
2. เปิด **Claude Code** หรือ **Codex** ในโฟลเดอร์ที่แตกไฟล์
3. พิมพ์ว่า

   ```
   อ่าน INSTALL-FOR-AI.md แล้วติดตั้งเกมนี้ให้หน่อย
   ```

AI จะเช็คว่าเครื่องขาดอะไร ถามเราก่อนติดตั้งของที่ขาด ทดสอบเกมในโหมดทดสอบ แล้วสร้างไอคอน **หมู่บ้านหมาป่า** บนเดสก์ท็อปให้

ถ้าดับเบิลคลิกแล้ว Windows ขึ้นหน้าเตือนความปลอดภัย (เพราะไฟล์มาจาก ZIP ที่โหลดจากเน็ต) ให้ AI ปลดบล็อกไฟล์ให้ตามขั้นแรกใน `INSTALL-FOR-AI.md` หรือกด **More info → Run anyway**

## เปิด / ปิดเกม

- **เปิด:** ดับเบิลคลิกไอคอน **หมู่บ้านหมาป่า** บนเดสก์ท็อป (หรือ `start.bat` ในโฟลเดอร์เกม) → จะมีหน้าต่างดำเปิดค้างไว้ + เบราว์เซอร์เปิดหน้าเกมให้
- **ปิด:** กด **ปิดเกม** ที่หน้าแรก หรือปิดหน้าต่างดำ
- เปิดซ้ำตอนเกมเปิดอยู่แล้ว = แค่เปิดหน้าเว็บของเกมเดิม

## ตั้งค่า AI และเสียง

ที่หน้าแรกกด **ตั้งค่า AI และเสียง**

- ติ๊กค่ายที่จะให้เล่น · ค่ายที่ยังไม่พร้อมจะติ๊กไม่ได้และบอกว่าขาดอะไร
- **รุ่น** — ค่าเริ่มเหมือนในคลิป (`claude-opus-5-5` · `gpt-6.1-sol` · `gemini-4-argon`) แก้เป็นรุ่นอื่นได้
- **ทดสอบ** — เรียก AI สั้นๆ 1 ครั้งเพื่อเช็คว่าใช้ได้ (ใช้โควต้า 1 ครั้ง)
- **คีย์ Gemini** — วางแล้วกดบันทึก · คีย์เก็บในเครื่องเราเท่านั้น (`data/gemini_key.txt`) ไม่ถูกส่งไปไหนนอกจาก Google
- **เสียงพากย์** — เสียง Gemini มีปัญหาบรรทัดไหน เกมจะใช้เสียงฟรีแทนบรรทัดนั้น

**คีย์ Gemini แบบฟรี:** อาจใช้รุ่น `gemini-4-argon` หรือเสียง Gemini ไม่ได้ และโควต้ารายวันต่ำ ถ้าทดสอบไม่ผ่านให้ลองเปลี่ยนเป็นรุ่น Flash · Google อาจเอาข้อมูลจากคีย์ฟรีไปพัฒนาโมเดล

**คีย์ที่ขึ้นต้นด้วย `AQ.`:** เป็นคีย์แบบใหม่ของ Google (คีย์ที่สร้างใหม่ใน AI Studio ตอนนี้เป็นแบบนี้ทั้งหมด) ใช้กับเกมได้เหมือนคีย์ `AIza` แบบเก่า

## ปุ่มลัดในห้องเกม

`F` เต็มจอ · `Space` หยุด/เล่นต่อ · `[` `]` ช้าลง/เร็วขึ้น · `H` ซ่อนบันทึก · `M` ปิด/เปิดเสียง · `R` เฉลยค่าย AI (ตอนจบ) · `C` สลับหน้าตาขาวดำ/สี

## แก้ปัญหา

| เห็นข้อความ | ทำยังไง |
|---|---|
| ยังไม่ได้ติดตั้ง Claude Code / Codex | ให้ AI ติดตั้งตาม `INSTALL-FOR-AI.md` |
| ยังไม่ได้ล็อกอิน Claude Code | เปิด terminal พิมพ์ `claude` แล้วล็อกอินด้วยแพ็กของเรา |
| ยังไม่ได้ล็อกอิน Codex | เปิด terminal พิมพ์ `codex login` |
| Claude Code เวอร์ชันเก่าเกินไป | เปิด terminal พิมพ์ `claude update` |
| แพ็กของคุณใช้รุ่นนี้ไม่ได้ | เปลี่ยนรุ่นในหน้าตั้งค่า |
| โควต้าเต็ม | รอให้รีเซ็ต หรือเลือกค่ายอื่นไปก่อน |
| คีย์ Gemini ใช้ไม่ได้ | เช็คว่าก๊อปคีย์มาครบ แล้วบันทึกใหม่ |
| คีย์ฟรีของ Gemini ใช้รุ่นนี้ไม่ได้ | เปลี่ยนรุ่นของ Gemini เป็นตระกูล Flash เช่น `gemini-3.8-flash` (รอรีเซ็ตไม่ช่วย) |
| AI ตอบช้าเกินไป | บางช่วงเซิร์ฟเวอร์ AI ช้าเอง ลองใหม่อีกครั้ง |
| เสียงฟรีกดไม่ได้ | ยังไม่ได้ติดตั้ง Python หรือ edge-tts → ให้ AI ติดตั้งให้ |
| ไมค์กดไม่ได้ | ไมค์ใช้ได้เฉพาะเครื่องที่มีการ์ดจอ NVIDIA และต้องติดตั้งตัวแปลงเสียงก่อน → ให้ AI ทำขั้น "Mic" ใน `INSTALL-FOR-AI.md` · ปุ่มไมค์ขึ้นเฉพาะตอน "ฉันเล่นด้วย" |
| มี Claude Code แต่เกมหาไม่เจอ | เกมหาจาก PATH, `~\.local\bin` และตัวที่มากับแอป Claude desktop ให้เองแล้ว ถ้ายังไม่เจอ ให้ใส่ที่อยู่ไฟล์ `claude.exe` ใน `data/settings.json` ตรง `"paths": { "claude": "…" }` (เพื่อความปลอดภัย หน้าเว็บตั้งค่านี้ไม่ได้) |

ข้อมูลของเราอยู่ในโฟลเดอร์ `data/` (ค่าที่ตั้ง · คีย์ · เกมที่เคยเล่น) ลบโฟลเดอร์นี้ = เริ่มใหม่หมด
